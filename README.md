# 제갈도원 객체지향 콘솔게임

### 게임 이름 : 수집 제작 타운라이프 ()


### 컨셉
- 마을을 중심으로 필드에 입장해 자원을 수집
- 상점에 판매 하고 건물을 성장


### 루프
마을 이동 -> 필드 입장 -> 자원 수집 -> 인벤토리가 가득 참 -> 마을 귀환 -> 상점 판매
-> 건물 업그레이드 -> 필드 입장 

### 시스템 
마을 
1. 네모난 격자형 필드
2. 마을에는 상점, 필드 입장, 건물이 존재 
3. 해당 타일 에서 상호작용 키를 눌러서 입장

상점 
1. 수집한 자원을 판매
2. 판매 시 돈 획득
 

필드  
1. 다이아 : 극희귀
2. 금 : 희귀
3. 은 : 중간
4. 동 : 가장 많이 등장

건물
1. 창고 (인벤토리 확장)
2. 연구소 (희귀 자원 확률 증가)
3. 상점 (판매 자원 가격 상승)
